# kray

A simple ray tracer built with modern C++(23) and SDL3.

Requires [CMake](https://cmake.org/) 3.28+ and
[vcpkg](https://github.com/microsoft/vcpkg) with `VCPKG_ROOT` exported.

## Build & Run

If [Only](https://github.com/onlyjs/only) is installed, the same workflow is available through the project `Onlyfile`:

```bash
only build
only build-release
only run
only run-release
only fmt  # requires clang-format
```
